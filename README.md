# 한국어 발음·읽기 V1.4.16 학생용 — 모바일 카드 수정본

## GitHub에 올리기
1. ZIP을 압축 해제합니다.
2. GitHub에 로그인하고 https://github.com/jhk644/Korean-practice 를 엽니다.
3. 기존 저장소의 루트에서 Add file → Upload files를 선택합니다.
4. 압축 해제한 폴더 안의 index.html, practice.html, reading.html, reading-view.html, static 폴더, data 폴더, README.md를 함께 올립니다. 바깥 폴더나 ZIP 자체를 올리지 마세요. 같은 경로의 기존 파일을 교체합니다.
5. Commit changes를 누른 뒤 Actions에서 Pages 배포 완료를 확인합니다.
6. https://jhk644.github.io/Korean-practice/ 에서 새로고침합니다. 이전 화면이 나오면 브라우저 캐시를 지우거나 새 시크릿 창에서 확인합니다.

기존 GitHub Pages 설정은 그대로 사용합니다. 주소를 변경할 필요가 없습니다.

## 포함 자료
- 업로드 원본 V1.4.16의 18개 언어, 전체 단계 목록, 68개 어휘 단원, 2,242개 어휘를 보존했습니다.
- 원본의 읽기 52개와 현재 공개 사이트에 추가된 읽기 84개를 모두 보존했습니다. 총 136개 자료, 1,300개 문장입니다.
- 원본에 자료가 없는 0·5단계는 목록을 유지하되 빈 상태로 표시됩니다. 초기 선택은 자료가 있는 단계로 맞췄습니다.
- 관리자 페이지, 서버, 비밀번호, API 키, 피드백 제출 기능은 포함하지 않습니다.

## 화면 수정
모바일 어휘 카드를 두 영역으로 고정했습니다. 위쪽 단어와 아래쪽 번역을 구분선으로 나누며, 정답 공개 전에도 아래쪽 공간을 유지합니다. 긴 번역은 줄바꿈과 글자 크기 축소를 적용하고, 극히 긴 경우 영역 내부에서 스크롤합니다. 낮은 화면에서는 화면을 스크롤하여 모든 버튼을 사용할 수 있습니다.
데스크톱의 기존 카드 크기와 배치는 유지했습니다.

## 음성과 의문문
단어·문장 3회 듣기는 기기의 한국어 음성을 사용합니다. 물음표를 포함한 원문 전체를 음성 엔진에 전달합니다. 의문문 끝의 상승 억양은 기기·음성에 따라 다르며 이 수정본에서 억양 교정을 보장하지 않습니다. 일정한 발음과 억양이 필요하면 별도 녹음 음성을 사용하는 방식이 적합합니다.

## 로컬 확인
HTML 파일을 직접 더블클릭하지 말고 웹 서버로 열어 주세요. Windows에 Python이 있다면 압축 해제 폴더에서 `python -m http.server 8000`을 실행한 후 http://localhost:8000/ 에 접속할 수 있습니다.
