# 한국어 발음연습 - 학생용 공개 V1.0

V1.3.17의 학생 기능을 GitHub Pages용으로 분리했습니다. Python 서버와 API 키가 필요하지 않습니다.

## 포함 기능
언어·KIIP 단계·단원 선택, 양방향 카드 학습, 한국어 0.80 속도 3회 듣기, 학습 표시, 순서 섞기, 복습 6종, 혼합 복습 언어 선택.
관리자 화면·로그인·AI 번역·저장·삭제·수정 요청 게시판은 포함하지 않습니다.

## 현재 교재
사용 중인 V1.3.17 폴더의 교재 34개 과 / 1229개 항목 / 14개 언어를 포함했습니다. 패키지 생성 시점의 복사본이며 PC의 후속 수정은 자동 반영되지 않습니다. 자료는 방문자가 열람·다운로드할 수 있습니다.

## GitHub Pages 게시
1. 무료 GitHub 계정에서 새 공개 저장소를 만듭니다.
2. ZIP을 풀고 그 안의 index.html, practice.html, static, data, README.md, .nojekyll을 저장소 최상위에 올립니다. 바깥 폴더나 ZIP 자체를 올리지 않습니다.
3. 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
4. Branch는 main, 폴더는 /(root)를 선택해 Save 합니다.
5. 배포 완료 후 Pages에 표시된 HTTPS 주소를 열어 확인하고 학생에게 주소 또는 QR코드를 공유합니다.
기본 주소 형태: https://계정명.github.io/저장소명/
별도 도메인이나 PC 상시 실행이 필요하지 않습니다. 아직 이 ZIP을 실제 GitHub에 게시하지 않았습니다.

## 교재 갱신
1. PC의 관리자 프로그램에서 데이터 백업 → 교재 데이터 백업 다운로드를 누릅니다.
2. 기존 공개용 교재 파일을 별도로 백업합니다.
3. 새 파일 이름을 lessons.json으로 정하고 GitHub 저장소의 data/lessons.json을 교체해 커밋합니다.
4. 배포 완료 후 공개 주소를 새로고침하여 확인합니다.
교재 파일만 교체하세요. server.py, feedback.json, 삭제 전 백업, 환경변수 파일, API 키, 비밀번호는 업로드하지 않습니다. 공개용 ZIP도 관리자 프로그램의 data 폴더에 덮어쓰지 않습니다.

## 로컬 미리보기
HTML 파일을 더블클릭하는 대신 ZIP 폴더에서 간단한 웹 서버로 확인합니다. Python이 설치된 PC라면 이 폴더에서 터미널을 열고 다음을 실행합니다.

python -m http.server 8000

PC: http://127.0.0.1:8000
같은 Wi-Fi 휴대폰: http://PC의IPv4주소:8000
이는 로컬 미리보기용입니다. 외부 학생은 GitHub Pages 주소로 접속합니다.

## 음성과 복습
갤럭시 Chrome에서 확인된 기기 음성 방식을 유지합니다. 다른 기기에서는 음성 종류와 지원 여부가 다를 수 있습니다. 아이폰 Safari는 실제 기기로 확인하세요.
한국어 → 번역어 중간·최종 복습은 5초 뒤 정답 공개, 역방향과 혼합 복습은 클릭 공개입니다. 중간 복습은 과 번호 순으로 앞 절반, 최종 복습은 해당 단계 전체를 사용합니다. 혼합 복습은 선택 언어의 빈 번역을 제외하고 최대 20개를 추출하며 같은 한국어가 다른 언어로 나올 수 있습니다.
학습 표시와 음성 선택은 각 브라우저에 저장되며 기기 간 자동 동기화되지 않습니다.
